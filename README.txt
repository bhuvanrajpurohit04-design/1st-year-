# 👻 Haunted Maze: The Learning Ghost

Pure Java Swing game with dynamic AI difficulties (Random Walk, A* Pathfinding, and Q-Learning).

## How to Run:
1. Make sure Java JDK is installed (`java -version`).
2. Open terminal/cmd in this extracted folder.
3. Compile:
   javac HauntedMaze.java
4. Run:
   java HauntedMaze

## Controls:
- Arrow Keys or W/A/S/D: Move Player (🧙)
- Goal: Collect all candies (🍬) and reach the exit door (🚪) while escaping the ghost (👻).
- 🎃 Pumpkin triggers Trick or Treat!
